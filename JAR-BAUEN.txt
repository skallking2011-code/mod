JAR KOSTENLOS ONLINE BAUEN (ohne Installation)

1. Auf github.com kostenlos registrieren, oben rechts "+" -> "New repository" -> Name: texturemixer -> Create.
2. "uploading an existing file" anklicken. Den INHALT dieses Ordners hineinziehen
   (inkl. des versteckten Ordners .github - falls der nicht mitgeht: Dateien einzeln
   "Add file -> Create new file" mit Pfad .github/workflows/build.yml und Inhalt einfuegen).
   -> "Commit changes".
3. Oben auf "Actions" -> "Build Mod" -> "Run workflow".
4. Nach ca. 2-5 Minuten: auf den gruenen Lauf klicken -> unten bei "Artifacts" -> texturemixer-jar herunterladen.
5. Die .jar aus dem ZIP in .minecraft/mods legen, zusammen mit Fabric Loader + Fabric API fuer 26.2.

Wenn der Lauf ROT ist: auf den Lauf klicken, den Fehlertext kopieren und an Claude schicken.
